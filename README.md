# AegisFlow

> **Real-Time Payment Fraud Scoring and Agentic Anti-Money-Laundering (AML) Investigation Platform**

AegisFlow is an enterprise-grade financial-crime platform uniting high-velocity machine learning fraud scoring with an autonomous, multi-agent AI investigation workbench powered by **LangGraph**, **TreeSHAP**, **Redis**, **Qdrant**, and **PostgreSQL**.

---

## 🏛️ System Architecture Overview

AegisFlow integrates two core operational engines:

1. **Real-Time Fraud Scoring Engine**:
   - Ingests incoming payment transactions with low latency.
   - Enriches events with online sliding-window velocity, behavioral, and graph metrics from Redis.
   - Computes calibrated fraud probability using **XGBoost** (Champion) with **LightGBM** (Challenger) running in shadow mode.
   - Evaluates deterministic override rules (e.g. Sanctions list hits, impossible travel).
   - Generates top-5 **TreeSHAP** explanation reason codes for every transaction decision (`APPROVE`, `REVIEW`, `DECLINE`).

2. **Agentic AML Investigation Workbench**:
   - Correlates high-risk alerts into investigation cases.
   - Orchestrates a specialized 6-agent LangGraph workflow (**Supervisor**, **Link Analyst**, **Pattern Analyst**, **Adverse Media Researcher**, **Narrative Writer**, **QA Reviewer**).
   - Queries a hybrid dense + sparse vector index in **Qdrant** for adverse news articles using `bge-small-en-v1.5` embeddings.
   - Generates regulator-grade FinCEN SAR drafts with traceable evidence citations.
   - Mandates human analyst sign-off before exporting any SAR draft.

## 🚀 Quickstart & Setup Guide

### 1. Prerequisites
- Docker & Docker Compose
- Python 3.11+
- Node.js 18+ (for frontend)

### 2. Environment Configuration
Copy the template configuration file:
```bash
cp .env.example .env
```

### 3. Quick Run (Instant Local All-in-One Server)
Launch the entire platform with one click or command (includes unified API gateway, live synthetic transaction streaming, ML models loaded, and interactive web workbench on port 8000):

**Windows (1-Click Batch Launcher):**
Double-click `run.bat` or run:
```cmd
run.bat
```

**Python Direct:**
```bash
python run_server.py
```
Open **[http://localhost:8000](http://localhost:8000)** in your browser!

### 4. Containerized Microservices Run (Docker Compose)
Launch PostgreSQL, Redis, Qdrant, MLflow, and microservices:
```bash
docker-compose up -d
```

## 🎲 Synthetic Data Generator (`txgen`)

AegisFlow includes a synthetic transaction generator capable of simulating realistic payment networks, Gaussian amount distributions, diurnal activity, shared-device fraud rings, and money laundering typologies:

- **Smurfing (Structuring)**: Sub-threshold deposits ($9,000–$9,800) aggregated into a master account.
- **Layering**: Rapid multi-hop transfers (A -> B -> C -> D) obfuscating origin of funds.
- **Round-Tripping**: Cyclical loop transfers (A -> B -> C -> A) returning funds to the originator.
- **Shared-Device / IP Fraud Rings**: High-velocity transactions across multiple accounts operating on identical device fingerprints.

### CLI Usage Commands

```bash
# Seed initial population of entities (Accounts, Devices, IPs, Merchants, Graph Edges)
python -m txgen.main seed-entities --num-accounts 1000 --num-devices 500 --num-ips 400 --num-merchants 200

# Generate batch synthetic dataset with injected fraud rings and typologies
python -m txgen.main generate-batch --count 10000 --fraud-ratio 0.05

# Inject specific typology on-demand
python -m txgen.main inject-typology --typology smurfing
python -m txgen.main inject-typology --typology layering
python -m txgen.main inject-typology --typology round_tripping

# Stream transactions continuously into database
python -m txgen.main stream --rate 5
```

> [!IMPORTANT]
> **Ground-Truth Label Isolation**: Ground-truth labels generated by `txgen` are strictly persisted in the `ground_truth_labels` table and are **NEVER** accessible to real-time serving APIs or online feature lookups.
